# LoopGuard – Infinite Loop Detection

## Overview
LoopGuard is a Theory of Computation case study that explores infinite loop detection using Turing Machines and computability concepts.

## Objectives
- Understand the Halting Problem.
- Analyse infinite loops using Turing Machines.
- Study decidability and undecidability.
- Explore the limitations of exact loop detection.

## Key Concepts
- Turing Machines
- Halting Problem
- Decidability
- Computability Theory
- Infinite Loops

## Conclusion
The Halting Problem proves that no general algorithm can perfectly determine whether every program will terminate. LoopGuard explores practical approaches and the theoretical limitations of infinite loop detection.

## Domain
Theory of Computation (FLA)
